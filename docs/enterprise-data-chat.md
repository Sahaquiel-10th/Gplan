# 管理员企业数据对话

管理员在现有文字聊天输入框开启「企业数据」，本轮允许 AI 查询已接入的万里牛数据。开关按会话保留；新对话默认关闭。钉钉/百炼知识库仍按原链路自动召回，不受此开关影响。

## 当前查询范围

- 店铺目录、当前库存覆盖的仓库编码、商品与 SKU 资料、源品牌。仓库名称及无当前库存记录的历史仓库可通过现有实时只读接口核实。
- 当前分仓库存：实际、锁定、可用、在途、残次品、快照时间。
- 销售出库：日期、店铺、商品、仓库的汇总、排行和明细，源金额与成本。
- 品牌销售笔数：对每个品牌按出库单据ID去重，同一单中多个同品牌SKU只计1笔；金额、件数、笔数三类占比均由数据库计算。
- 采购入库：日期、商品、仓库、供应商的汇总和明细，批次及生产/效期。
- 连接器所属企业的各资源最后成功同步时间。
- 现有万里牛 AI Skill 已允许的官方只读接口，供实时问题或数据库未覆盖的查询使用。

不接入支付宝、不新增业务写接口、不允许模型执行自由 SQL。实时查询沿用已有 CLI 和服务端凭证；仅 `WANLINIU_COMPANY_ID` 对应企业允许使用，未配置时限定 `company_default`。数据库查询始终绑定当前用户的 `companyId`。

## 口径及限制

销售出库金额不等于平台成交额、净销售额、到账金额或净利润。采购入库不代表全部类型的入库。金额按源币种分组，币种缺失按企业约定默认人民币 CNY；缺失金额和成本不按零补齐。

出入库必须有起止日期，统一北京时间、包含两端，单次最多366天。当前库存不支持历史快照或直接按店铺筛选。每页最多100行，分页结果和上下文裁剪明确标注；数据库汇总在分页之前计算。实时接口沿用已有分页能力，结果一律注明不能视为全量统计。

公司全部品牌销售额/占比及日期追问使用受控确定性规划（未指定日期默认最近30天；上周/上上周按周一至周日），不依赖模型先返回查询JSON。其他问题每轮最多两次规划、六个受控查询或一次现有实时查询流程。规划调用、查询和最终回答设有时间限制。来源信息随回答保存，审计记录只保存来源、筛选和覆盖信息，不重复存储原始业务结果。

对已确认的公司单日数据进行全面分析时，采用七项受控查询覆盖当日品牌、品牌笔数、店铺、商品、采购入库、当前库存和目标日前7天的日汇总。历史对照的默认周期会在来源说明中标明。明确指定的店铺、品牌筛选和比较周期继续交由通用规划处理。知识库保持独立自动召回，规划器只负责万里牛查询。

数据准备阶段预算为45秒，最终模型回答单独限时120秒，并受模型网关已配置的上限约束。每条SQL在数据库端按剩余预算限时执行。失败的范围停止重复分页，已经成功的分组在后续总计或同步水位失败时继续提供，并标明部分结果。来源展示数据准备、规划、查询的分段耗时；最终回答超时提示单独标明回答阶段和请求号。模型超时计时覆盖读取完整响应正文。

综合分析追问优先覆盖各维度的数值与解读，品牌采用头部及异常摘要，减少重复整张品牌表占用输出空间。上游返回输出长度截断标记时，正文附明确提示，并随会话保存。

DeepSeek、豆包官方预设的综合分析使用6000输出token额度。普通调用使用环境配置的默认输出额度；查询规划和连接测试使用各自较短额度。

## 权限与记忆

后端使用数据库内当前账号角色，拒绝普通用户伪造 `enterpriseData:true`。受限成员智能体不允许扩大为全企业数据范围。公开分享和机器人接口不会继承管理员数据权限。

会话一旦开启企业数据，即标记为受限会话；关闭开关只停止新查询，已有历史仍仅原企业管理员本人可读。查询步骤前后、发送最终模型请求前、保存回答时均检查权限；降权或停用账号后不返回企业数据回答。关联附件同样校验权限，受限会话和附件不使用浏览器缓存。

企业数据会话不进入自动记忆同步，也不能通过记录消息、保存整段对话等接口写入通用记忆；知识库仍照常检索。手动复制到另一个普通对话属于用户主动提供的新内容，不由系统自动传播。

## 本地验证

运行 `npm run test:enterprise-data`、`npm run test:operations`、`npm run test:workspace`、`npm run test:client-api`、`npm run test:wanliniu` 及 `npm run build`。

企业数据 HTTP 测试在临时目录使用合成账号、模型和数据库结果，不读取项目 `.env` 或真实数据。它验证真实聊天路由、两轮规划、上下文组装、知识库自动召回、分页覆盖、历史权限、降权竞态和记忆隔离。该测试不代表生产 RDS 查询性能、真实万里牛接口或真实模型选工具准确率已经验收。

## 统计性能与覆盖说明

品牌分析先解析日期与所需指标，昨天／前天／今天以请求开始时的北京时间为准，单个明确日期按单日查询；无法识别的明确时间段交给通用规划器，不回退为30天。金额与件数使用SKU预聚合，笔数使用独立受控查询按品牌、出库单据去重。不能将一次汇总成功视为整个任务完成，来源展示同时说明所需指标是否齐全、各查询步骤、返回字段、耗时及企业数据上下文字数与摘要；不在日志重复存储原始业务明细。

笔数占比以同范围、同币种的公司去重出库单总数为分母。混合品牌单据会分别计入相关品牌，因此该占比合计可能超过100%，不能改用明细行数或悄悄更换分母以凑到100%。

发布前通过 `scripts/ensure-enterprise-indexes.mjs` 幂等创建销售单头与明细的在线统计索引（LOCK=NONE）。查询在服务端发现索引后使用；旧数据库保留日期索引路径。业务表和原始币种字段不被改写。

完整范围先汇总再分页。返回请求范围天数、实际有记录天数和首末业务日期；未出现记录的日期不自动解释为零销售或已完成同步。只有同步状态成功而业务查询失败时，整体显示未取得结果；混合成功/失败显示部分查询成功。
