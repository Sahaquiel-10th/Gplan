## 逐个添加

1. 选择“添加账户”，在弹窗填写公司名称、来源、账户名称、币种。尾号和备注可以留空。公司填开户公司全称；账户名称是自己起的内部识别名，不是银行账号、登录名或开户户名；人民币币种填CNY。所有字段附就地说明。
2. 同公司名称归入一个内部主体；不同租户中同名公司仍隔离。公司名称是登记信息，不代替银行侧法人身份验证。
3. 保存后为未配置凭证草稿，不请求银行、不启动同步。以后补尾号、备注或配置凭证。
4. 已关联支付宝应用后，不允许从清单改换公司、来源、名称或币种，避免凭证误绑；备注及尾号仍可修改。资料更新使用修订号，过期编辑会拒绝覆盖。

## 删除填错的账户

账户行的“删除账户”打开确认弹窗，必须完整输入账户内部识别名；服务端重新检查实时角色、租户、账户修订号、名称确认及最新关联凭证修订。无凭证草稿可由管理员删除；有关联凭证的账户必须在指定管理员有效维护窗口内删除，会同时停用对应支付宝配置。旧有未关联清单的支付宝配置，可在安全维护中删除。

删除采用后台停用标记并保留审计，不注销银行/支付宝账户，不触碰ERP或其他业务数据。停用记录从清单与凭证列表隐藏，旧ID无法查询、更新、检测或复活；在途检测或密钥生成也不能写回已删除账户。需要再次接入时重新添加，生成新ID；名称或APP_ID不被停用记录永久占用。页面不提供恢复按钮。

清单删除接口：`DELETE /api/admin/data-platform/finance-directory/accounts/:id`，请求含`revision`、`confirmName`；关联凭证时还须带`linkedAlipayRevision`。旧未关联凭证删除接口：`DELETE /api/admin/data-platform/alipay/accounts/:id`，请求含`revision`、`confirmName`；已关联清单的配置不能从后者单独删除。

## 批量导入流程

1. 下载空白模板，用Excel打开填写，再另存为“CSV UTF-8（逗号分隔）”。首版不支持直接上传xlsx/xls。
2. 表头必须完整保留六列：公司名称、银行/来源、账户名称、账号尾号、币种、备注。可调整列顺序，不能新增密钥或完整账号列。
3. 银行/来源使用页面显示的十二个标准名称；币种填有效三位代码，如CNY。账号尾号仅填四位数字或留空，前导零按文本保留。Excel录入前可将尾号列设为文本。
4. 单文件256KB以内，每次最多500条账户；每租户清单最多1000个账户。文件在内存解析，不存公共上传目录、不记入通用日志。
5. 点击“预览并检查”，查看逐行结果。公司＋来源＋账户名称＋币种相同且其他资料一致时跳过；资料有冲突时要求在台账中明确编辑，不自动覆盖。
6. 文件内重复、格式错误、超长内容、不支持来源、完整账号、公式或明显私钥/口令片段均会报错。任何一行出错，整批不写入；错误预览不回显被拒绝的原始内容。
7. 确认时服务器重新解析并校验预览摘要与当前台账修订。文件、用户、租户或台账发生变化则要求重新预览。导入前不改数据库；校验通过后再整体赋值，避免JSON Store发生半批写入。
8. 再次导入相同文件会跳过已有账户，不产生重复资料。批量导入仅用于清单，不导入实际流水、余额或凭证。

## 凭证与清单分开

不需要加密主密钥或维护窗口就能登记非凭证清单；凭证配置依然要求服务器限时开放、指定管理员及有效主密钥，仍支持完成后持久锁定。清单不能解锁配置窗口，也不提供任意银行网关或自由API调用。

开放维护窗口后，支付宝账户行可选择“配置与检测”，在单户弹窗带入公司和账户名称。弹窗中分“填写凭证”和“接口检测与结果”，保存后自动切到结果区，不跳转到其他页面；只显示此账户。关闭后保留原列表筛选，并把键盘焦点还给触发按钮。存在未保存内容时关闭会提醒，正在提交时不允许关闭；未保存的凭证修改不能直接检测旧配置。

保存/生成密钥时服务器验证清单归属、来源、名称和唯一关联，并在慢操作完成后再次核查。配好的应用不能擅自改绑另一账户。早期独立支付宝配置可在“安全维护”集中查看，编辑同样打开单户弹窗。

“接入准备”按12个来源折叠展示要求；银行账户行直接打开对应准备弹窗，不假装已有可用银行凭证表单。“安全维护”中的全局锁定操作默认折叠，并明确它会关闭整个企业的凭证维护入口，不是仅关闭某一个账户。账户登记、凭证锁、查询与同步的权限语义均未改变。

台账分开显示：凭证未配置/待补齐/已保存，检测未开始/待复核/通过/失败，以及自动同步未启用。通过检测不等于已入库或自动同步，其他银行只显示待规范与授权要求。

## 路由

前缀 `/api/admin/data-platform/finance-directory`，受管理员会话与租户保护；所有响应禁缓存，变更请求拒绝跨站来源。

| 方法与路径 | 用途 |
| --- | --- |
| GET `/` | 本租户来源、主体、账户和非敏感阶段状态 |
| GET `/template.csv` | 带UTF-8 BOM的六列表头模板，无客户数据 |
| POST `/accounts` | 保存无凭证草稿 |
| PUT `/accounts/:id` | 带修订号更新本租户资料 |
| POST `/imports/preview` | 提交CSV文本，仅解析和预览 |
| POST `/imports/commit` | 提交同一CSV文本及预览摘要，重新校验后整批添加 |

审计只记操作者、租户、账户ID、操作和新增数量，不记凭证、完整CSV或备注。无删除/解锁/任意银行请求接口。
